# v0.1.0 — First public release

Date: 2026-10-10

## Highlights

- **Dual-engine AWS auditing** — Prowler and ScoutSuite run together; findings are deduplicated across both engines, with a boto3 fallback when neither CLI is installed.
- **Scanner modes** — AWS mode (real credentials) and Demo mode (simulated findings, no AWS needed) with results scoped per mode across Dashboard, History, Findings, Remediation, Comparison, and Reports.
- **Per-scan AWS identity** — every scan records the STS `GetCallerIdentity` account ID and ARN on its assessment (shown in History), so multi-account results stay attributable.
- **Findings workspace** — search, filter, sort, severity badges, remediation status tracking.
- **Reports** — HTML / JSON always; PDF via WeasyPrint where GTK/Pango system libraries are present.
- **Assessment history & comparison** — score trend, severity deltas, side-by-side view.
- **Optional AI** (off by default) — summaries, remediation advice, and Q&A against any OpenAI-compatible endpoint over HTTPS. Rate limited.
- **Local-first auth** — first-run account setup, hashed passwords, localhost binding, CSRF protection, login rate limiting.
- **CI** — pytest matrix on ubuntu + windows, Python 3.10 and 3.14, plus an advisory `pip-audit` job.

## Install

See the README quick start (Windows and Linux). Tests: `pip install -r requirements-dev.txt && python -m pytest tests -q`.

## Known limits

- Python 3.10–3.14 only (3.15 wheels not yet available for all pinned dependencies).
- Localhost only — do not expose without HTTPS, reverse-proxy hardening, and multi-user controls (see SECURITY.md).
- PDF export needs GTK/Pango system libraries; HTML and JSON exports always work.
- AWS keys live in `~/.aws` — the app never asks for or stores them.
